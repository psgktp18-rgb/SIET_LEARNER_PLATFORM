# Interactive Features Roadmap

Building interactivity for all 59 pages is a massive undertaking. We will tackle "everything" by breaking it down into focused sprints:

## Sprint 1: Core Academics (Assignments & Grading)
*   **Teacher**: Create Assignments (Forms, File Uploads, Due Dates).
*   **Teacher**: View Submissions & Grade (Marks entry, Feedback).
*   **Student**: View Assignments, Upload Submissions, View Grades.
*   **HOD/Admin**: View aggregated marks updates.

## Sprint 2: AI & Study Materials
*   **Teacher**: Upload Notes, trigger AI Flashcard/Question Generation.
*   **Student**: Study Flashcards (Spaced Repetition), Take Practice Quizzes.
*   **Student**: Chat with Doubt Bot (RAG with citations).

## Sprint 3: Live Classroom
*   **Teacher**: Start Meet, QR Attendance generation, Live Polls.
*   **Student**: Scan QR Attendance, Join Meet.

## Sprint 4: Admin & Configuration
*   **Admin**: User Management Forms (Create, Block, Reset Password).
*   **Admin**: System Settings & AI Fallback toggles.
